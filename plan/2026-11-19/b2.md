## 3. Luồng nghiệp vụ chi tiết

### 3.1 Cây danh mục công khai (UC-CAT-01 — API 5.1, 5.2)
1. `GET /public/categories` → `CategoryTreeService.publicTree()`: đọc Redis `categories:tree:all` (JSON đã dựng); trượt → `findAll()` (một truy vấn, ≤ vài trăm dòng), lọc `isActive` theo D5, sắp `display_order NULLS LAST, name`, dựng cây theo `parentId`, ghi Redis TTL 1 giờ. Trả `[{ id, name, slug, icon, children[] }]`.
2. `GET /public/categories/{slug}` → tìm theo slug trong cây đã cache (không có / bị ẩn → `404 GNE-CAT-4041`), trả `description`, `breadcrumb` (đường từ gốc), `children` (cấp kế tiếp, chỉ hiển thị), `product_count` (D7, cache cùng TTL ở khóa `categories:count:published`).
3. Header HTTP: `Cache-Control: public, max-age=300` cho 2 endpoint (SSR của web gọi mỗi trang).

### 3.2 Quản lý cây (UC-CAT-14 — API 11.11)
- `GET /admin/categories` → cây đầy đủ (kể cả ẩn) + `commission_rate` (phần trăm, `null` = dùng mặc định), `product_count`, `shop_count` (D7) + `summary { root_count, child_count, product_count, pending_proposals }`. Không cache (Admin cần số mới).
- `POST /admin/categories` `{ name, slug, parent_id, icon, commission_rate, is_active, description, requires_business_license }` → kiểm D3, D4, D16; `commission_rate` khác `null` ⇒ cần `UPDATE_COMMISSION` (thiếu → `403 GNE-SEC-4030`) và kiểm D1 qua `changeCommissionRate()`; `display_order = max(anh em) + 1`; `201` bản ghi như GET.
- `PATCH /admin/categories/{id}` (trường bất kỳ) → khóa dòng `findByIdForUpdate`; đổi `parent_id` kiểm D4; đổi `commission_rate` như trên + audit `COMMISSION_UPDATED`; `200`.
- `DELETE /admin/categories/{id}` → D6, `204`.
- Mọi thay đổi: sau commit xóa `categories:tree:all`, `categories:count:published`, `cat:attrs:{id}` (và của con cháu khi đổi cha).

### 3.3 Cấu hình hoa hồng (UC-CAT-14 bước 8–9 — API 11.8, `UPDATE_COMMISSION`)
- `GET /admin/commission-settings` → `{ default_rate, categories: [{ category_id, name, rate, is_enabled }] }` cho **danh mục cấp 1** (theo màn mock — kiểm ở C00.03); `is_enabled = commission_rate != null`; `rate` khi tắt = mặc định.
- `PATCH { default_rate }` → D2; audit `COMMISSION_UPDATED` (`scope = DEFAULT`).
- `PATCH { categories: [...] }` → một transaction, khóa các dòng theo thứ tự `id` (tránh deadlock); `is_enabled = false` ⇒ `commissionRate = null`; mỗi dòng đổi thật ghi một audit (`scope = CATEGORY`); danh mục không tồn tại → `404 GNE-SYS-4040` cả lô.
- Thêm hàm đọc dùng cho plan đơn hàng sau này: `CategoryFacade.effectiveCommissionRate(categoryId)` (ngành → cha gần nhất có cấu hình → mặc định). Thứ tự "riêng của shop" ở `VendorProfile` do module order / vendor ghép — không làm ở đây.

### 3.4 Bộ thuộc tính (UC-CAT-15 — API 11.11, `MANAGE_CATALOG`)
- `GET /admin/categories/{id}/attributes` → danh sách của ngành (sắp `display_order`) + `inherited` (D8); `values` = parse `allowedValuesJson`.
- `POST …/attributes` → D8, D10; `201` (+ `grace_period_days` theo D11).
- `PUT …/attributes/{code}` → D9, D10, D11; `200`.
- `PATCH …/attributes/{code}` `{ is_active }` → D12; `200`.
- Sau commit xóa `cat:attrs:{id}` của ngành và **mọi ngành con cháu** (vì kế thừa).
- `CategoryFacade.attributesFor(categoryId)` (gồm kế thừa, chỉ `isActive`) — cổng cho plan sản phẩm (UC-CAT-09) và tìm kiếm (UC-CAT-05) dùng sau; đọc qua cache `cat:attrs:{id}`.
